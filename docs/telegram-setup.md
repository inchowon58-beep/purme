# 텔레그램 문의 알림 설정 (초간단 가이드)

문의가 오면 텔레그램 앱으로 “띵!” 하고 바로 오게 만드는 방법입니다.

## 한 줄 요약

1. 텔레그램에서 **로봇 친구(봇)** 를 만든다  
2. 그 로봇이 **나한테만** 쪽지를 보내게 연결한다  
3. 사이트에 **열쇠 2개**(토큰 + 내 번호)를 적어 둔다  

---

## 1단계. 텔레그램 앱 설치

핸드폰에 **Telegram** 앱을 설치하고 가입합니다.  
(카카오톡처럼 채팅하는 앱입니다.)

---

## 2단계. 봇 만들기 (BotFather)

1. 텔레그램 검색창에 `@BotFather` 를 검색합니다.  
2. 파란 체크(인증) 있는 **BotFather** 를 누르고 **시작(Start)** 합니다.  
3. 채팅창에 이렇게 보냅니다.

```text
/newbot
```

4. BotFather가 “봇 이름 뭐로 할래?” 라고 물으면 예:

```text
푸르메정원 문의알림
```

5. 그다음 “유저네임(아이디) 정해줘. 끝은 반드시 bot” 이라고 하면 예:

```text
purme_alert_bot
```

(다른 사람이 이미 쓰면 다시 물어봅니다. 다른 이름으로 바꾸면 됩니다.)

6. 성공하면 **긴 비밀번호(토큰)** 가 나옵니다.  
예: `7123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxx`

👉 이 값이 `TELEGRAM_BOT_TOKEN` 입니다.  
**남에게 보여주면 안 됩니다.** (집 열쇠와 같아요)

---

## 3단계. 내 채팅방 번호(Chat ID) 찾기

⚠️ **중요:** `@purme_alert_bot` 같은 건 **봇 사용자명**입니다.  
`TELEGRAM_CHAT_ID` 에는 넣으면 **안 됩니다.**

Chat ID는 **내 텔레그램 방 번호(숫자)** 입니다. 예: `123456789`

### 방법 A (쉬움)

1. 방금 만든 봇을 검색해서 들어가 **시작(/start)** 을 누릅니다.  
2. 텔레그램에서 `@userinfobot` 을 검색해 시작합니다.  
3. 봇이 숫자(예: `123456789`)를 알려줍니다.  

👉 이 숫자가 `TELEGRAM_CHAT_ID` 입니다.

### 방법 B

1. 내 봇에게 아무 말이나 보냅니다.  
2. 브라우저 주소창에 아래를 넣고 열어봅니다.  
   (`토큰` 자리에 2단계 토큰을 넣기)

```text
https://api.telegram.org/bot토큰/getUpdates
```

3. 나온 글 속에서 `"chat":{"id": 123456789` 같은 숫자를 찾습니다.

---

## 4단계. 사이트에 열쇠 넣기

### 로컬(내 컴퓨터) 테스트

프로젝트 폴더에 `.env.local` 파일을 만들고:

```env
TELEGRAM_BOT_TOKEN=여기에_봇_토큰
TELEGRAM_CHAT_ID=여기에_내_채팅_숫자
```

그다음 개발 서버를 다시 켭니다.

```bash
npm run dev
```

메인 페이지 하단에서 **상담 신청**을 한 번 해보면,  
텔레그램으로 문의 내용이 와야 합니다.

### Vercel(실제 사이트) 배포

1. Vercel 프로젝트 → **Settings** → **Environment Variables**  
2. 아래 두 개를 추가합니다.

| Name | Value |
|------|--------|
| `TELEGRAM_BOT_TOKEN` | BotFather가 준 토큰 |
| `TELEGRAM_CHAT_ID` | 내 chat id 숫자 |

3. **Redeploy**(다시 배포) 합니다.  
   (변수만 넣고 배포를 안 하면 적용이 안 됩니다.)

---

## 5단계. 잘 됐는지 확인

1. 사이트에서 문의 폼을 제출합니다.  
2. 텔레그램에 이런 메시지가 오면 성공입니다.

- 이름 / 전화 / 문의 유형 / 내용 / 시각

문의는 관리자 페이지에도 그대로 저장됩니다.  
텔레그램이 잠깐 고장 나도 **문의 접수는 실패하지 않게** 만들어 두었습니다.

---

## 자주 하는 실수

- 봇에게 **/start** 를 안 함 → 메시지 안 옴  
- Chat ID를 잘못 넣음 → 안 옴  
- Vercel에 변수 넣고 **재배포 안 함** → 안 옴  
- 토큰을 카톡/단톡에 올림 → 다른 사람이 내 봇을 쓸 수 있음 (즉시 토큰 재발급)

토큰을 다시 만들고 싶으면 BotFather에게 `/revoke` 또는 `/token` 을 보내면 됩니다.

---

## 코드가 하는 일

문의가 저장되면 서버가 텔레그램에게 말합니다.

> “이 사람한테 이 내용 보내줘”

그때 쓰는 주소:

`https://api.telegram.org/bot{토큰}/sendMessage`
